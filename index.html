Projects

Rest Time & WMS Outbound Monitoring System

Built solo end-to-end — from the frontend and dashboard logic to the authentication infrastructure — using vanilla JavaScript and Firebase (Authentication + Realtime Database), without a heavy framework yet still real-time and multi-user. Hardened for security (session-only auth, modular auth guards) and used daily by the Palangka Raya DC operations team.

JavaScriptFirebase AuthRealtime Database HTML / CSSSession Auth GuardAudit Trail
Main Navigation
Control Panel WMS

Sidebar navigation to 4 main modules (Rest Time Monitoring, Aging & Packer Backlog, Occupancy & Shift, Log Update) plus System Settings. The "Live Monitoring Info" panel shows top volume, critical aging (>D-4), and estimated area capacity — all in real time.

Module 01
Rest Time Monitoring

An activity input form via OpsID scan/entry with auto time-logging, plus bulk import from Excel/CSV. Four summary cards (Total MP Checked In, Actual MP Rest, Done Rest, Total MP Remaining) update in real time, with multi-criteria filters (shift, status, department, search) and automatic compliance status per operator.

Module 02
Aging & Packer Backlog

An automatic executive summary rounding up volume, critical backlog, and priority routes from the latest import. Two destination grids (high & mid-low volume) show aging status per route (Danger/Warning/Good) with a full D-Day to D-5 breakdown, plus cards for total parcels, bulky, high value, and liquid packed items.

Module 03
Occupancy & Shift Departure

Volume & aging-days breakdown per route for Inner and Outer Island, plus a "Priority Action Center" highlighting the 5 routes with the highest occupancy for early loading. A parcel-volume comparison chart per shift helps evaluate workload across shifts.

Modul 04
Shift Departure Schedule & Heatmap

Monitoring keberangkatan linehaul per shift dengan status real-time (Terjadwal / Segera <30 menit / Lewat Jadwal), dikelompokkan per slot dan rute — total 51 unit linehaul terpantau per hari, dengan filter cepat per shift.

Audit Trail
Log Update — Import History

A complete record of every file ever imported — file name, import time, who imported it — so data-change history stays traceable, with an option to delete individual log entries.

Security
Session-Only Login Screen

A minimal, dark-themed login gate for internal DC staff — email and password fields backed by Firebase Authentication with session-only persistence, so nobody stays logged in on a shared warehouse terminal. New accounts aren't self-service: admins provision them directly in the Firebase Console (Authentication → Users), keeping access tightly gate-kept.
